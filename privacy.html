Privacy policy

Loadwise collects nothing. This page says what that means in practice.

The app

Loadwise does not ask Android for permission to use the internet, so it cannot send or receive anything. It has no account, no adverts, no analytics and no tracking.

Your jobs, materials, rates, settings and logo are kept in the app's private storage on your phone. They are left out of Google's cloud backups. Uninstalling the app removes them.

A PDF, a spreadsheet file or a backup file is made only when you ask for it, and goes only where you send or save it. The backup file is not encrypted, so keep it somewhere you trust.

"Check for updates" and "More apps" hand a web address to your browser. What happens next is between your browser and that website.

This website

This site uses no cookies, no analytics and no tracking. It is hosted by GitHub Pages, and GitHub may log visits as described in GitHub's privacy statement. App files are downloaded from GitHub.
